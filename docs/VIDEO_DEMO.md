# Four-minute Welcome Kit + Welcome Wave demo

This is a recording plan for the public Welcome Kit site and the local Welcome Wave application. Use one engineer, one project, and one question throughout the video. Record actual screen states and record IDs; do not put provider keys or private settings on screen.

## Prepare before recording

1. Open the public Welcome Kit site and `http://localhost:8000/app` in separate browser tabs. Use a 1920×1080 capture with system audio and microphone enabled. Close unrelated tabs and notifications.
2. In Welcome Wave, open the **Welcome-Kit** project. In **Settings → Repository**, confirm `VijayabaskarR-06/welcome-kit` says **Ready**. Do not say that a KT recording exists unless you have uploaded and indexed one.
3. In **Team → Enrol**, enrol the demonstration hire as a backend engineer, select a mentor and a program template, then review the drafted plan in **Approvals**. This is required before the hire's Voice page becomes available. Use the real hire account when filming the hire view.
4. Rehearse the exact Guide question: **“Where is mission progress stored, and what happens when I complete a mission?”** Confirm the answer cites `src/lib/mission.ts` or `src/App.tsx`. If the live answer lacks a source, use another question and show only the evidence the app actually returns.
5. For a Voice segment, check **Settings → Integrations**, the tool tunnel, microphone permission, and a short test call. The current Agora Platform preview has an unverified streaming transcript path. Keep the text Guide sequence as the reliable recording path.

## Editing and evidence rules

- Keep the screen recording continuous across each action. Cut waiting time, but do not splice a proposal and a different result into one apparent transaction.
- Zoom into repository status, a source citation, and one real record status. Show the full app context before each close-up.
- If the Voice transcript or custom tool call does not appear, remove that shot from the final video. Do not replace it with a prerecorded voice clip described as a live agent call.
- The Welcome Kit website is a standalone static experience. Its browser-local mission progress does not sync to Welcome Wave. The Welcome Wave app remains local at `localhost` for this demo; only the Welcome Kit site is public.
